Компонент waitPanel - панель ожидания

Исходники 
Панель можно показывать используя методы showWaitPanel(), hideWaitPanel().

import {showWaitPanel,hideWaitPanel} from '../../../accord/js/accord-bundle.js';

Либо просто подключить к странице accord-publish.js, который делает их глобальными.


import {showWaitPanel,hideWaitPanel} from '../../../accord/js/accord-bundle.js';

...

  showWaitPanel("test1");
  hideWaitPanel();
